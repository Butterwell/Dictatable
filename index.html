Dictatable

a stack and array language

A language designed to be dictated. As is, it fits that criteria. However, even I don't find it particularly readable. My expectation is that as I further develop phrases the language will become more readable. What is unlikely to change is the heavy use of arrays on a stack. Take an array or two from the top of the stack and perform an operation, and put the result back on the stack. Rinse. Repeat.

Basics

Just type into the area below. Try 30 30 random

30 30 puts a two element integer array on the stack. random pops that array and creates a thirty by thirty two-dimensional array of random numbers between zero and one. If you add round to that line, it pops that array and puts a array of only zeros and ones on the stack.

To define a command, use the keyword is and end the definition with period or . like this: grid is 30 30 random round. (or Grid. Every word is cast to lowercase.)

In Conway's Game of Life, a cellular automata, a cell is alive in the next iteration if it's currently alive and there are two alive neighbors or if it is dead and there are three alive neighbors. The following code does that. Add it to the Grid definition, above.
